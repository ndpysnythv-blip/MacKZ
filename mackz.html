MacKZ 是什么

MacKZ 是一个常驻菜单栏的 macOS 小工具。它会实时读取 MacBook 屏幕转轴的 开合角度，把你当前的桌面画面当成一块玻璃， 沿着屏幕边缘一路“折”下去——就像 iPhone Duo 折叠屏合上时的那段过渡动画。

它不是手机模型，也不是一段假动画：画面里被折叠的内容就是你的真实桌面， 所以 Dock、窗口、壁纸都会跟着一起翻折，合到哪一步、动画就停在哪一步。

它是怎么做到的

  • 读角度：通过 IOKit HID 读取 Apple 内置的 Lid Angle Sensor（vendor 0x05AC / product 0x8104），并把上报间隔压到 8 ms，角度变化几乎无延迟。
  • 抓桌面：用 ScreenCaptureKit 以零拷贝方式（IOSurface → Metal 纹理）拿到当前屏幕画面，不占 CPU 解码。
  • 折画面：四趟 Metal 渲染管线完成重投影 —— 射线投射还原折叠几何 → 横向高斯模糊 → 纵向高斯模糊 → 径向色散，做出玻璃的厚度、模糊与棱镜感。
  • 智能补完：跟随角度实时同步；一旦你停住不动，它会自动加速把剩余片段播完；再次反向移动则立刻取消加速、继续跟随。

真实角度跟随

停在半路会自动加速播完剩余片段；一反向就取消加速，不会抢你的操作。

全局覆盖

覆盖在所有窗口之上且跨全部空间，全屏 App 里也照常生效。

安装（终端一键）

打开「终端」，粘贴下面这行命令回车即可。 不需要在浏览器里下载、不需要处理“不受信任的开发者”提示： 脚本会在你本机拉源码、本机编译、本机签名，产物天生带信任。

curl -fsSL https://raw.githubusercontent.com/ndpysnythv-blip/MacKZ/main/scripts/install-raw.sh | bash

脚本会自动做这些事：检查 Xcode 命令行工具 → 优先整包下载源码（失败则逐文件回退，内置多个镜像并带超时保护） → 编译出 MacKZ.app → 装入「应用程序」→ 配置开机自启 → 启动，并顺带清理更新后残留的旧授权记录。

如果你更想手动下载

前往 Releases 下载 MacKZ.zip，解压后拖进「应用程序」。浏览器下载的文件会带隔离属性，第一次打开前执行：

sudo xattr -cr /Applications/MacKZ.app && sudo codesign --force --deep --sign - /Applications/MacKZ.app && open /Applications/MacKZ.app

使用步骤

  1. 装好后菜单栏出现 MacKZ logo 图标，说明插件已经跑起来了。
  2. 授权「屏幕录制」：首次启动会自动弹窗申请，同意后程序会自动重启生效。 若系统设置里明明勾着却仍显示未授权（更新后常见），点设置里的「修复权限」清掉过期记录再授权一次。
  3. 慢慢合上屏幕：角度进入「开始折叠角」（默认 90°）之后，桌面就开始被折下去；合到底动画完整结束。
  4. 中途停住：状态机会自动加速把剩余片段补完；一旦反向抬起，加速立刻取消，重新跟随你的手。
  5. 想让开盖也看得到：打开设置里的「合盖不休眠」，否则合盖即休眠、动画发生在锁屏之下，等于白做。

手机遥控（演示用）

设置面板的「手机遥控」里会显示一个局域网地址。手机连同一个 Wi-Fi，用浏览器打开它，就能远距离控制折叠动画：

  • 「合上」「打开」——播放一次完整的折叠 / 展开动画
  • 「播放一次开合」——自动演一遍
  • 进度滑块——实时拖动折叠程度

地址里的 t=xxxx 是每次启动随机生成的口令，只在局域网内有效，重启插件后自动更换；关掉开关即完全停止监听。

常见问题

菜单栏有图标，屏幕上却没有动画？

九成是「屏幕录制」权限没生效。MacKZ 用的是本地临时签名，每次更新后签名都会变，系统里保留的仍是上一版的授权记录，于是出现“设置里勾着、程序说没授权”。请在设置面板点「修复权限」，再点「申请授权」，然后按提示重启 MacKZ。

铰链角度一直显示 0°？

说明系统没有暴露 Lid Angle Sensor。Apple Silicon 的 MacBook 基本都有；Intel 机型或部分特殊机型没有，此时插件会自动切换为「开盖唤醒 / 合盖睡眠」触发，你也可以在设置里用「手动预览」的滑块和按钮完整体验动画。

合上屏幕后电脑休眠，开盖要输密码，动画根本看不到？

设置面板 →「合盖与休眠」→ 点「开启合盖不休眠」（需要一次性管理员授权）。合盖后系统继续运行、显示器照常关闭，开盖不会再因休眠弹锁屏。若仍要求输密码，那是「锁定屏幕」策略，点旁边的「打开「锁定屏幕」设置」，把「关闭显示器后需要密码」改为「永不」。
注意：合盖状态下机器仍在耗电、不散热，放进包里前请点「恢复系统默认」。

浏览器下载后提示“未受信任”打不开？

这是 macOS 对浏览器下载文件的隔离策略。推荐直接用上面的终端一键安装（本机编译，不带隔离属性）；如果已经下载了 zip，按安装区里那条 xattr + codesign 命令处理一下即可。

会不会影响我正常用电脑？

不会。覆盖层不接收鼠标事件，点击、拖动窗口、触控板手势全部照常；渲染是「有变化才画、静止就停」，空闲时几乎不占资源。菜单栏里也能随时一键停用。

动画方向感觉反了？

设置面板 →「常用设置」→「折叠方向」可以在「向下收」和「向上收」之间切换，改动即时生效。
